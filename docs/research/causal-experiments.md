# 比較実験と因果検証

> 旧 `docs/causal-analysis.md`・`docs/experimental-design.md` を統合した文書です。

## 1. 原則

- 「原因の説明（仮説）」と「因果的な検証（実験）」を分けます。
- LLM の説明（エージェントの rationale、Judge の根拠）は因果関係の証明として扱いません。
- 単なる相関も因果関係の証明として扱いません。
- 原因候補は、要因だけを変えた比較実験で効果が観察されるまで、「仮説」または「トレースで確認（因果は未検証）」にとどめます。
- 実験で支持された場合も、「この条件・この標本で効果が観察された」ことを示すだけで、一般的な因果の立証とは表示しません。

## 2. 実験の設計

- **条件の割り当て**
  - 研究者が条件を割り当てます。
  - 反復 r のシード（基準シード + r）は全条件で共通です。同じ外生価格系列で比べます。
  - 実行順は、条件の偏りを避けるためハッシュでばらします。
- **条件の固定**
  - 開始時に次を凍結し、SHA-256（`frozenHash`）を記録します。
    - 研究デザイン、規則の版、プロンプト、モデル設定、コードの版、トレースの記録モード
  - 開始後に変更はできません（下書きのみ編集可）。変更したい場合は、複製して新しい研究にします。
- **事前登録**
  - 研究課題・仮説・変数・分析計画を事前に記録します。
  - 評価基準（規則エンジン・事前基準の版）は開始時に固定されます。
  - 仮説の反証条件は、比較実験の前に仮説へ記録します。
- **反復の単位**
  - 独立な単位はセッション（条件 × 反復）です。
  - 同じセッション内の連続した判断は独立に扱いません。
    - 差の推定: 反復単位の対応のあるブートストラップ、符号反転の並べ替え検定
    - 回帰: セッション単位のクラスター頑健標準誤差
  - 判断を独立と仮定した χ² 検定・Wilson 区間は参考値と表示します。

## 3. ミニマルペア

| 対 | 雛形・仕組み |
|---|---|
| 「かつ」対「又は」 | 雛形 `spoof_and_or` |
| 「新規に」の有無 | 雛形 `short_new_existing` |
| 例外規定の有無 | 雛形 `position_limit_exception`（Phase 2 で追加。分類 `exception_change`） |
| 規則趣旨の提示の有無 | 条件の `includePurpose` |
| 参照文書（条文）へのアクセスの有無 | 条件の `presentRules` |
| ツール権限の違い | 対象外。金融市場シミュレーションにはツールがない（トレースに `tools: []` を記録） |

原因仮説から作る検証実験（`scheduleExperiment`）は、仮説の要因だけを変えた2条件（T / C）を、同じ市場・同じシードで実行します。

## 4. 要因実験

- 2×2（文言A/B × 趣旨なし/あり）＋規則なしの統制群（C4）を用意しています。
- ロジスティック回帰で主効果と交互作用を推定します。
  - セッション単位のクラスター頑健標準誤差
  - 完全分離の検出
- 効果量（Cohen の h、オッズ比）を示し、複数の比較には Holm 補正をかけます。
- 3要因以上は、条件（最大8）を組み合わせて作れます。専用の雛形はありません。

## 5. 原因仮説

各仮説に次を記録します（`Hypothesis`）。

| 項目 | 内容 |
|---|---|
| 原因候補の分類 `cause` | 次のいずれか。<br>規則文言の曖昧さ、接続詞・限定語、例外規定、目的関数、プロンプト、参照文書、RAG、アクセス制御、ツール権限、シミュレーション環境、評価器の誤判定 |
| 根拠 | Failure の件数、例、トレース ID |
| 検証状態 | 状態の履歴 |
| 必要な比較実験 | 要因は原則1つ、他は同一、反復10以上、評価基準は固定 |
| 反証条件 | T − C の 95% 区間が 0 を含む、または正の場合は支持しない |
| 検証結果 | `supported` / `refuted` / `inconclusive`、要約、検証実験の研究 ID |

- RAG・アクセス制御・ツール権限の候補は、その仕組みを持つ評価環境でのみ生成します。現在の環境では生成しません。
- 評価器の不一致による Failure からは、「評価器の誤判定」の仮説を作ります。検証には外部ラベルを使います。
- 外れ値・評価不能の Failure からは、原因候補を自動では作りません。

## 6. 注意（結果に自動で表示するもの）

- 介入で判定に使う規則が変わる場合、差には「行動の変化」と「判定基準の変化」の両方が含まれます。
- モックエージェントは規則・趣旨・目標を読まないため、行動の変化による効果は測定されません。
- 複数の要因を同時に変えた場合、または対応のある反復が少ない場合も注意を表示します。
- ランダム化されていない研究どうしの比較は記述的な比較とし、因果効果としては表示しません。

## 7. 限界

- 傾向スコア・操作変数など、観察データからの因果推論の手法は実装していません。
- 実 LLM での比較実験は未実施です（費用の承認が必要）。そのため、行動の変化による効果はまだ測定していません。
- サンプルサイズの事前計画（検出力分析）は未実装です。
