# Business Impact / PoC 評価

## 測定する価値

| 区分 | 指標 | 出所 |
|---|---|---|
| 時間 | 従来の作業時間・kisei 利用時の人の作業時間・システムの処理時間・削減時間 | 人の入力（実測／推定を区別）、処理時間は研究の実行時間から自動 |
| 新規リスクの検出 | 確認済みの発見・ルールチェッカー（形式判定のみ）で検出できない発見・誤検出・見逃し・未確認の疑い・網羅率 | Failure の確認状態（自動）と比較表（人の入力） |
| 修正案の有効性 | 作成・実験への使用の承認・提案としての承認・再実験・回帰テスト PASS・レビュー時間 | 修正案と回帰テスト（自動） |
| 副作用 | 誤拒否率の増加・新たな失敗・セッション時間の増加・費用の増加 | 回帰テストと再実験（自動） |
| 監査可能性 | 証拠付きの Failure・再現可能な実験・追跡可能なセッション・承認履歴の記録・トレースのないセッション | 研究データ（自動） |

## 誤った成果の表示を防ぐ規則

- 専門家が確認していない疑いは、確定した発見として数えません（「未確認の疑い」として別に表示）。
- 推定の作業時間は推定と明示し、入力がなければ時間削減を算出しません。
- モックデータを含む場合は、その旨をレポートの冒頭に表示します。
- 架空の成果を実測値として表示しません。

## レポート

検証目的・比較対象・実験条件・使用データ・検出された問題・重大度と証拠・修正案・改善効果・副作用・費用と時間・制約と不確実性・残課題を含みます。Markdown / JSON / CSV で出力し、PDF は印刷用のページからブラウザの印刷機能で保存します。
