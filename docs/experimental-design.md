# 実験デザインと比較（Phase 1-C）

## 研究（Study）

- 条件 × 反復のセッション。反復 r はシード（基準シード + r）を全条件で共通に使い、同じ外生価格系列で比べます。
- 実行順は条件の偏りを避けるためハッシュでばらします。
- 開始時に研究デザイン・規則の版・プロンプト・モデル設定・コードのバージョン・トレースの記録モードを凍結し、SHA-256 を記録します。
- 研究課題・仮説・変数・分析計画を事前に記録します（事前登録）。

## 雛形

- 2条件（条文A / 条文B）
- 2×2（文言A/B × 趣旨なし/あり）＋規則なしの統制群（C4）。主要比較は「文言B − 文言A（趣旨なし）」。

## 比較の指標と方法

| 指標 | 方法 |
|---|---|
| 規則違反率・拒否率・趣旨逸脱率・判定不能率・説明との不一致 | 比率と Wilson 95% 区間（判断を独立と仮定した参考値） |
| 条件間の差（リスク差） | 反復単位の対応のあるブートストラップ 95% 区間、符号反転の並べ替え検定、Holm 補正 |
| 効果量 | Cohen の h、オッズ比 |
| 要因の効果 | ロジスティック回帰（主効果・交互作用、セッション単位のクラスター頑健標準誤差、完全分離の検出） |
| 経済・運用 | 損益の平均・SD・中央値・最小・最大、費用、セッションの実行時間 |
| 図 | 条件別の棒グラフ（区間）、フォレストプロット、ステップごとの規則違反率 |

χ² 検定・Fisher の正確検定は判断を独立と仮定した参考値として表示します。

## 研究どうしの比較

モデル・プロンプト・市場条件の異なる研究を並べて比較できます（記述的な比較。研究間は対応がないため差の検定は行いません）。

## 再現性マニフェスト

コミット SHA・判定エンジンとシミュレーターの版・エージェントの設定・プロンプトと規則のハッシュ・シードの規則・評価器の版・データの指紋（完了したセッションの結果のハッシュ）と、完全な再現を妨げる要因（LLM の確率性、モデルの更新、ローカル実行ではコードの版を特定できない）を出力します。
