# 因果分析の考え方

kisei では「原因の説明（仮説）」と「因果的な検証（実験）」を分けます。

1. 研究内の条件は研究者が割り当て、同じ反復では全条件で同じ外生価格系列（同じシード）を使います。条件以外の要因（市場・モデル・プロンプト）は凍結設定で揃えます。
2. ただし LLM の応答は確率的で、同じシードでも行動は一致しません。差の推定には反復単位の対応のある方法（ブートストラップ・並べ替え検定）を使い、不確実性を区間で示します。
3. 要因の効果はロジスティック回帰（主効果・交互作用）で推定し、標準誤差はセッション単位のクラスター頑健推定とします。クラスター数が少ない場合は注意を表示します。
4. 研究どうしの比較（ランダム化されていない比較）は記述的な比較とし、因果効果としては表示しません。
5. 原因の候補（仮説）は、トレースで裏付けられても「トレースで確認（因果は未検証）」にとどめます。「実験が効果を支持」は、要因だけを変えた統制実験の区間が 0 をまたがない場合に限ります。
6. 介入で判定に使う規則そのものが変わる場合（文言の差し替え）、差には「行動の変化」と「判定基準の変化」の両方が含まれることを注意として表示します。
7. モックエージェントは規則・趣旨・目標を読まないため、行動の変化による効果は測定されません（効果は判定基準の違いだけを反映し、その旨を表示します）。

## 限界

- 傾向スコア・操作変数など、観察データからの因果推論の手法は実装していません。
- 多数の要因・多水準の要因の同時推定、多重比較の厳密な管理は、主要比較と Holm 補正の範囲にとどまります。
