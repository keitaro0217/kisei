# 実行トレース（Phase 1-A）

## 記録の単位と構造

研究のセッション（1条件 × 1反復）ごとに1つのトレースを記録します。Span の ID は OpenTelemetry と同じ形式（traceId 32桁・spanId 16桁の16進数）です。

```text
session（episode）           研究・条件・反復・シード・モデル・規則の版・プロンプト・凍結ハッシュ
 └─ step N                   ステップ
     ├─ observe market       価格・直前約定・現金・保有・未約定（市場状態 ID = シード:ステップ）
     │   └─ match resting orders   未約定の指値の約定・取消
     ├─ present regulations  提示した規則の版・条文/趣旨の提示の有無（この版では検索は行わない）
     ├─ llm decision         モデル・トークン数・費用・レイテンシ・試行回数、入力（プロンプト）・出力（応答）
     ├─ order                提案された行動、判定・約定（解釈不能ならエラー）
     ├─ formal evaluator     判定・違反コード・規則違反の有無・閾値付近の度合い
     └─ intent criteria      趣旨逸脱の基準・AI の自己評価・引用した規則
```

モデルの呼び出しが失敗したセッションも、エラーの Span を含めてトレースを残します。記録するのはモデルの観測可能な入出力と操作だけで、モデル内部の非公開の思考を取得したとは扱いません。

## 本文の記録とセキュリティ

| 設定 | 動作 |
|---|---|
| メタデータのみ | 本文を保存しない |
| 伏せ字（既定） | API キーの形式・Authorization・パスワード・メールアドレス・10桁以上の数字列を伏せて保存 |
| そのまま | 本文を保存（機密情報を含む入力では使わない） |

- API キーと Authorization ヘッダーはどの設定でも記録しません（そもそもトレースに渡しません）。
- 記録モードは研究の開始時に凍結されます（開始済みの研究には後から影響しない）。
- 保存期間（既定 90 日）を過ぎたトレースはワーカーが削除します。
- 生ログへのアクセス制限: PARTIAL。現在はログインした全員が閲覧できます（個別アカウント・権限管理が未実装のため）。

## 画面

- 検索（研究・条件・反復・モデル・規則違反・趣旨逸脱・閾値付近・エラー・期間）
- 詳細（ツリー・時系列のバー・Span の詳細・入出力・問題のあるステップだけの表示・JSON / OTLP の出力）
- 判断（意思決定ログ）・規則・研究の結果への移動
