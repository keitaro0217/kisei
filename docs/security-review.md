# セキュリティレビュー

| 要件 | 状態 | 実装 |
|---|---|---|
| 認証 | COMPLETE | ログイン画面（共有パスワード）→ 署名付きセッション Cookie（HttpOnly・SameSite=Lax・本番は Secure・12時間）。スクリプトは Authorization ヘッダー。各 API・画面で再検証 |
| 総当たり対策 | PARTIAL | 接続元ごとに 10 回の失敗で 15 分拒否。インスタンスのメモリ内のみ（サーバーレスの複数インスタンス間では共有されない） |
| CSRF | COMPLETE | Fetch Metadata / Origin の検査、JSON の Content-Type 必須、SameSite=Lax |
| HTTPS・HSTS | COMPLETE | 本番は HTTPS 以外をリダイレクト・拒否 |
| API キーの暗号化・秘密情報のログ除外 | COMPLETE | AES-256-GCM、ログ・監査・トレース・エラーでの伏せ字 |
| 入力の検証 | COMPLETE | 規則 DSL（ホワイトリスト・深さ・要素数の上限、eval なし）、研究デザイン、評価、監視イベント（不明な項目を拒否） |
| SSRF | COMPLETE | 既存の LLM クライアント（許可したホスト以外のプライベート IP を拒否） |
| XSS | COMPLETE | React のエスケープ、HTML を直接挿入しない。CSV は数式インジェクション対策 |
| SQL インジェクション | COMPLETE | すべてプレースホルダー（動的な列名は固定の候補からのみ） |
| レート制限 | PARTIAL | 監視の取り込みは接続元ごとに1時間あたりの上限。研究 API には上限なし |
| 予算制御 | COMPLETE | 既存のプロバイダーごと・全体の月間予算。研究・Judge・検証実験も同じ呼び出し経路 |
| 権限チェック | PARTIAL | Permission で API ごとに検査するが、共有アカウントは全権限を持つ |
| 監査証跡 | COMPLETE | 規則・研究・評価・Failure・仮説・修正案・回帰テスト・PoC・監視・ログインの操作 |
| データの保持期間 | COMPLETE | トレース（既定 90 日）・監視イベント（接続元ごと、既定 30 日） |
| 外部連携の明示的な許可 | COMPLETE | 外部への自動転送はない。監視の取り込みは接続元ごとのトークン（ハッシュのみ保存、作成時に1度だけ表示） |
| プロンプトインジェクション対策 | PARTIAL | Judge には証拠をデータとして渡し区切りタグを除去。RAG は未実装 |
| 個別ユーザー・ロール（admin / researcher / viewer）・テナント分離 | NOT IMPLEMENTED（監視のみテナント列で分離） | 共有パスワードのみのため、マルチテナント SaaS として本番提供しない |

## 注意

- 監視（試験版）は個別アカウント・権限管理がないため、外部企業の本番データの接続には使わないでください。
- トレースの本文（プロンプト・応答）はログインした全員が閲覧できます。機密情報を含む入力を扱う場合は記録モードを「メタデータのみ」にしてください。
