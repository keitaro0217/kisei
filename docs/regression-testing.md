# 回帰テスト（Phase 3-B）

## 実行方式

承認済み（指定すれば候補も）のテストケースを、修正前と修正後の規則で、記録した取引所の状態から決定論的に判定し直します。LLM は呼ばないため費用はかからず、同じ入力からは常に同じ結果になります。

| データセット | 期待 | 合格の条件 |
|---|---|---|
| 既知の Failure・閾値付近 | 防ぐ（期待する趣旨が「適合」の場合は受理） | 拒否される |
| 正常な行動 | 受理 | 受理される（拒否は誤拒否） |
| 修正済み | 防ぐ | 拒否される（再発がない） |

修正の対象の規則を使っていないケースは「対象外」として集計から除きます。提示方法だけを変える修正は形式判定を変えないため、効果は再実験（行動の比較）で評価します。

## ゲート

閾値（設定可能）: 誤拒否率の上限・防げた割合の下限・修正済みの成功率・データセットごとの最小件数・再実験の追加費用の上限。

| 判定 | 条件 |
|---|---|
| FAIL | 点推定が閾値を満たさない、修正済みの再発、追加費用の超過 |
| INCONCLUSIVE（判断保留） | 件数が最小件数未満、または点推定は満たすが 95% 区間が閾値をまたぐ |
| REVIEW_REQUIRED（要確認） | 未承認のケースや期待する趣旨が未確定のケースを含む |
| PASS | すべての閾値を 95% 区間で満たす |

件数が少なく区間が広い場合は PASS にしません。

## 再実験

修正前（対照）と修正後（処置）を、元の研究と同じ市場・同じシード・同じモデルで実行し、規則違反率・損益・費用・セッションの実行時間・失敗したセッションを比べます。
